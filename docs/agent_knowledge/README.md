# Agent Knowledge Library

This directory is the canonical, reviewable source of reusable Agent knowledge.
Store one accepted fact, decision, risk, regression, pattern, or procedure per
file under `entries/`.

Subagents propose knowledge in task handoffs. The Chief records each proposal as
accepted, rejected, or deferred. Promote only accepted items with provenance and
independent verification. Task-local evidence remains in its task packet.

Indexes, embeddings, databases, and profile views are derived artifacts and
never outrank these files. Conflicting active entries must be surfaced together
for review.
