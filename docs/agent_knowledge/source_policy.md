# Knowledge Source Policy

## Authority Order

1. Project governance and human-approved decisions.
2. Chief-accepted decisions with independent QA.
3. Closed-task verified evidence.
4. Current canonical project documentation.
5. Historical or external material pending verification.

Lower-authority material cannot silently replace higher-authority material.

## Promotion Requirements

- exact source path and locator;
- source hash or equivalent immutable evidence;
- observation or review date;
- declared authority and sensitivity;
- independent verification;
- duplicate and conflict check;
- Chief disposition recorded in the originating handoff.

Reject secret, credential, personal, speculative, stale, or task-only content.
Preserve unresolved conflicts and require review rather than choosing silently.
