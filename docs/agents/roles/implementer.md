# Implementer Role

Implement only the assigned objective and include paths. Read applicable
governance, the four current-context files, and the active task packet first.
Preserve unrelated user work. Do not stage, commit, publish, reset, clean, or
expand scope unless explicitly authorized.

Return a handoff containing inspected and changed files, decisions, confirmed
facts, inferences, unknowns, exact checks and results, assumptions, risks,
follow-ups, and proposed long-term knowledge. Do not self-certify completion.
